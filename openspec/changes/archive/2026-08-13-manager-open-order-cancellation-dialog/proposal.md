# Proposal: manager-open-order-cancellation-dialog

> **Kind**: product usability correction, not a sequenced roadmap change. **Gate**: a manager cancels an open order through the same focused, reason-required dialog pattern as a bill.

This changes presentation and focused coverage only; it does not change order cancellation writes, adapters, gates, offline handling, or access control.
